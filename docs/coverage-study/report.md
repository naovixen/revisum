# Coverage study

## Sample

- Date: 2026-10-28. Files read at the pinned commit linked from each intent.
- Suites (10, ten intents each): Cal.com, Grafana, Supabase Studio, Rocket.Chat, Saleor Dashboard and WordPress Gutenberg (Playwright); Mattermost (Cypress); MediaWiki (WebdriverIO); OpenProject (Capybara with Selenium); Cypress Real World App (Cypress, the one demo app).
- Sampling rule: in each suite's main end-to-end folder, take spec files in alphabetical order and the first test case of each, skipped ones included, until ten intents. Where a folder has fewer than ten files (MediaWiki, Real World App), take the second test of each file from the top.
- Judging rule: setup counts as expressible only when the plan can do it through the UI, or when it is a standing precondition of a test environment (a test account, default content, an enabled feature). API or database seeding of test-specific records does not count; nor does a value that must be unique on every run.
- This section is added by hand; rerunning the tool removes it.
